A+ Study 🎓

A+ Study is a multilingual educational platform designed to help students learn, solve academic problems, and make better decisions through personalized support.

✨ Features

📚 Study

A dedicated space for students to ask academic questions and receive helpful explanations across different subjects.

💭 Decision

A supportive space where students can share their concerns and receive calm, practical, and personalized guidance.

🌍 Multilingual Interface

The platform supports:

- English
- Persian
- Korean
- Chinese
- Japanese
- Spanish

🎨 Theme Support

Users can choose between:

- Light Mode
- Dark Mode
- System Default

🖼️ Image Features

The platform is designed to support image-based learning and image generation with daily usage limits.

📱 Responsive Design

The interface is designed to work across desktop and mobile screen sizes.

🛠️ Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript

🎯 Project Goal

The goal of A+ Study is to combine education, technology, and personalized support in one simple and accessible platform for students.

The project is being developed as a portfolio project with the long-term goal of becoming a fully AI-powered educational platform.

🚀 Current Status

Prototype / Portfolio Project

The current version includes the main interface, Study and Decision modes, multilingual UI, theme support, responsive design, and demo interaction logic.

AI-powered features are planned for future versions.

🔮 Future Development

Planned improvements include:

- Real AI integration
- Personalized AI tutoring
